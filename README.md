## 🇷🇺 О проекте

**SoundBridge CLI** — удобная консольная утилита на C# (.NET), которая позволяет транслировать аудиопоток из музыкальных приложений (**Yandex Music**, **Spotify**, **iTunes**) в виртуальный микрофон для использования в Discord, играх и других программах.

### ✨ Возможности
- 🎨 **Красивый интерфейс командной строки** на базе `Spectre.Console`.
- 🔍 **Автоматическая проверка** наличия установленного виртуального аудиокабеля при старте.
- 🌐 **Поддержка двух языков** (русский / английский).
- 🎵 Поддержка популярных музыкальных сервисов.

### ⚙️ Требования
1. ОС Windows.
2. Установленный [.NET SDK](https://dotnet.microsoft.com/) (версии 6.0 или выше).
3. Установленный виртуальный кабель (например, [VB-Audio Virtual Cable](https://vb-audio.com/Cable/)).

## 🇬🇧 About

**SoundBridge CLI** is a C# (.NET) console utility that lets you stream audio from music apps (**Yandex Music**, **Spotify**, **iTunes**) into a virtual microphone for use in Discord, games, and other software.

### ✨ Features
- 🎨 **Rich CLI interface** powered by `Spectre.Console`.
- 🔍 **Automatic check** for Virtual Audio Cable presence on startup.
- 🌐 **Language selection** (Russian / English directly at startup).
- 🎵 Support for popular music streaming apps.

### ⚙️ Requirements
1. Windows OS.
2. [.NET SDK](https://dotnet.microsoft.com/) (v6.0 or higher).
3. A Virtual Audio Cable (e.g., [VB-Audio Virtual Cable](https://vb-audio.com/Cable/)).

### 🚀 Installation & Running
1. Clone the repository:
   ```bash
   git clone [https://github.com/your-username/SoundBridgeCli.git](https://github.com/your-username/SoundBridgeCli.git)
   cd SoundBridgeCli
2. Run the utility:
   ```bash
   dotnet run
3. Enjoy!
